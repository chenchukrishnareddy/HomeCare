# HomeCare

Household cleaning and maintenance reminder app.

### Included
- Daily, weekly and monthly tasks
- Garden and home-maintenance categories
- Family-member assignment
- Completion tracking
- Progress indicator
- Local storage
- Mobile-friendly design
- PWA foundation

### Run
Open `index.html` in a browser.

### Publish with GitHub Pages
After uploading the files to the repository, go to **Settings → Pages**, select the `main` branch and `/ (root)`, then save.

### Planned next version
